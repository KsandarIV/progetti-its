# Project work di project management: assistente legale con RAG

Esercitazione del modulo di project management (Italdigit), ITS. **Lavoro di gruppo (5 persone).**

Il gruppo ha pianificato, per uno sponsor simulato, un assistente legale basato su RAG per studi legali e studenti: dalle user stories alla WBS, al Gantt, al percorso critico e al controllo dei costi con l'Earned Value. Il progetto è stato pianificato, non realizzato.
